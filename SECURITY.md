# Sicherheit

Sicherheitsrelevante Hinweise bitte nicht als öffentliches Issue mit vertraulichen Details veröffentlichen. Kontakt: kontakt@bloxxstar.de

API-Schlüssel, Zugangsdaten, Tokens und Passwörter dürfen niemals in das Repository committed werden. Spätere Geheimnisse werden ausschließlich als GitHub Secrets oder Server-Umgebungsvariablen gespeichert.
