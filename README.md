# BloxxStar Tools V6

Upload: Den gesamten Inhalt dieses Ordners in das Hauptverzeichnis von `tools.bloxxstar.de` kopieren und vorhandene Dateien ersetzen.

Enthalten:
- Steinepreis-Rechner
- Preis-pro-100-g-Rechner
- responsive Startseite mit Community-Bereich
- Bezugsquellen & Rabattcodes mit 11 Partnern
- Suche und Kategorien
- Rabattcode-Kopierfunktion
- transparenter Hinweis vor Shop-Weiterleitung
- Dark-/Light-Mode
- barrierearme Navigation und Tastaturbedienung

Hinweis: Die Shop-Logos werden online über den jeweiligen Domain-Logo-Dienst geladen. Falls ein Logo nicht verfügbar ist, erscheint automatisch der Shopname als barrierearmer Fallback.
